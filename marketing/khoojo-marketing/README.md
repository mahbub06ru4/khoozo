- **Description** in Bangla and English
- **CTA button** to choose in Ads Manager
- **Primary text** in Bangla and English, inside a grey box. Copy the whole box: hashtags are already at the end
- **Targeting suggestions** at the bottom of the file

## Before every boost

1. Read the **Before boosting** list at the top of the file. Fill in any `[PLACEHOLDER]` (links).
2. **Facts must be true today.** Prices, discounts, batch dates and features must match the live site/app. Delete a line rather than publish something that isn't ready.
3. **Feature lists for Office, Real Estate and Travel Agency SaaS are built from the site's short descriptions plus standard modules** (payroll, installments, visa cases…). Check them against the current build before boosting.
4. **Meta ad policy:** no wording that assumes the viewer's personal traits ("Are you in debt / Muslim / sick?"), no guaranteed visas or jobs, no fake numbers or "No. 1" claims, and keep text on images short.
5. Facebook doesn't render markdown. The grey boxes are already plain text with emojis, so paste them as they are.

## Bangla or English?

- Default for Bangladesh audiences: the **Bangla** version.
- Run the **English** version for expat / diaspora audiences (UAE, KSA, Malaysia, UK), corporate decision-makers, or as an A/B test in the same ad set.
- Set the ad set **language** to match: Bengali for the Bangla post, English for the English post.
